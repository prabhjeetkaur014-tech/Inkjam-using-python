# inkJam – Python Backend & Analytics Engine

A modern blogging web platform powered by a comprehensive **Python** backend and data science stack.

> **Visual Preservation Guarantee**: The complete frontend visual design, HTML templates, CSS styles (`style.css`), typography, and user interface remain 100% identical and unchanged to the original design, while the backend is fully powered by Python.

---

## 🛠️ Python Libraries Used

This project utilizes the exact requested Python libraries:

| Library | Role & Integration |
|---|---|
| **`numpy`** | Used in `analytics.py` for numerical computing: calculating word count distributions, mean/median reading time statistics, standard deviation, variance, and ratings aggregates. |
| **`pandas`** | Used in `analytics.py` and `database.py` for structured DataFrame manipulation: category breakdowns, subscriber plan distributions, age demographic binning, and automated CSV data exporting. |
| **`matplotlib`** | Used in `analytics.py` to create publication-quality charts: review ratings horizontal breakdown, multi-panel executive summary dashboard, and data dispersion plots. |
| **`seaborn`** | Used in `analytics.py` for statistical visualizations: posts-per-category countplots and kernel density estimation (KDE) histograms of post lengths with styled color palettes. |
| **`tkinter`** | Used in `admin_gui.py` to provide a full-featured desktop administration and analytics management console with tabbed navigation, live treeviews, and moderation controls. |
| **`photoimage` & `pillow` (PIL)** | Used in `generate_assets.py` to generate the official brand logo (`img/logo.png`) and in `admin_gui.py` to dynamically load, resize, and display data charts within the Tkinter desktop window. |
| **`flask`** | Python web backend framework serving static pages and REST API endpoints (`/api/sync`, `/api/posts`, `/api/signup`, `/api/login`, `/api/analytics`, etc.). |

## 🚀 How to Run

### 1. Install Requirements
```bash
pip install -r requirements.txt
```

### 2. Launch Everything (Default)
Starts the Python backend server, opens the web application in your browser, and opens the **Tkinter Desktop Admin Console**:
```bash
python run.py
```

### 3. Dedicated Run Modes

- **Run Web Server Only**:
  ```bash
  python run.py --server
  # Open in browser: http://localhost:5000
  ```

- **Launch Desktop Admin GUI Only**:
  ```bash
  python run.py --gui
  ```

- **Generate Analytics & Charts Only**:
  ```bash
  python run.py --analytics
  ```

- **Export Database Tables to CSV (Pandas)**:
  ```bash
  python run.py --export
  ```

## 🔒 Content Moderation & Security
The Python backend enforces server-side validation and content filtering for banned words (`database.py`), preventing inappropriate content from being saved to the database. All endpoints validate inputs and hash/protect sensitive session information.
